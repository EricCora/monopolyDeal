# Bots have names

## Problem
A bot seat shows up as "Player 2", "Bot 1" or "Bot", which says nothing and reads like an empty seat.

## Outcome
Every bot has a person's name, on web and iOS, in local games, online rooms and nearby tables.

- Names are random, so a bot isn't called the same thing every game.
- Local setup: switching a seat to Bot clears a default "Player N", and the field reads "Random bot name". Switching it back to Human restores "Player N". A name you typed is never replaced.
- When the game starts, each bot seat without a name of its own draws one that nobody at the table has.
- Online rooms and nearby tables: an added bot draws a name nobody at the table has.

## Constraints
- Lifetime stats are keyed by player name, so each bot name gets its own row.
- Same list, same order on web, the room server and iOS: `src/ai/botNames.ts` and `DealEngine/BotNames.swift`.
- No names of the people who play: Eric, Anna.

## Non-goals
- "House Bot" (practice) and "Daily Rival" (daily challenge) keep their names.
- No renaming bots after a game starts, and no change to saved games or stats.

## Verification
Unit tests for the name rules on both sides, room and nearby tests for added bots, `npm run quality` and `npm run ios:verify -- --skip-ui`, and a look at the web setup screen.
