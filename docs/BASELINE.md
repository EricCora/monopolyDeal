# Baseline and Guardrails

This document is the operational baseline for the full audit and modernization program.

## Runtime and install

- Node.js: `20+` (Node `22` recommended)
- Package manager: `npm`
- Install dependencies:

```bash
npm install
```

## Core run commands

- UI only: `npm run dev`
- UI + multiplayer server (same machine): `npm run dev:all`
- LAN UI + multiplayer server (cross-device): `npm run dev:lan:all`
- Build/typecheck: `npm run build`
- Lint: `npm run lint`
- Tests: `npm run test`

## Quality and baseline scripts

- Full quality gate: `npm run quality`
  - Runs `lint` -> `test` -> `build`
- Repo tree snapshot (default depth 3): `npm run tree`
  - Optional depth: `node scripts/print_tree.mjs 4`
- E2E/smoke:
  - `npm run e2e:smoke`
  - Runs Playwright/Cypress if configured; otherwise runs smoke UI tests.

## Environment variables and defaults

From `.env.example` and runtime defaults:

- `VITE_MULTIPLAYER_API_URL` (optional)
  - Default resolution: local hosts use `http://localhost:8787`; otherwise current `window.location.origin`.
- `VITE_MULTIPLAYER_PUSH_ENABLED` (default `true`)
- `VITE_MULTIPLAYER_REACTIONS_ENABLED` (default `true`)
- `MULTIPLAYER_PUSH_ENABLED` (server default `true`)
- `MULTIPLAYER_REACTIONS_ENABLED` (server default `true`)

## Determinism path (required)

Deterministic runs are already supported and must remain stable:

- Engine game creation supports seeded initialization via `createGame({ seed })`.
- Deck order is generated by seeded RNG and deterministic shuffle.
- AI rollout supports deterministic seeds through `chooseMonteCarloAction(..., { seed })`.
- Multiplayer room start supports optional `seed` in the start payload.

Program rule: any new random behavior must either use existing seeded paths or add a deterministic seed path before merge.

## Local multiplayer setup

Recommended local flow:

1. Start services with `npm run dev:lan:all`.
2. Host creates room from Multiplayer screen.
3. Joiners use room code or invite link (`/join/:roomCode`).
4. Use `Refresh`/reconnect controls if network state degrades.
